# OUTCOMES

Fulfilment and donor-feedback system for Minhaj Welfare Foundation.

Salesforce gifts that need feedback (orphan sponsorship, Hifz, water, housing...) come in as instructions. OUTCOMES routes each to its project framework, tracks delivery, and produces the donor feedback. It does not manage money.

Built step by step, module by module, to be handed to MWF developers and later folded into the CRM.
